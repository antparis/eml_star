# eml★ — Minimal Anti-Holomorphic Extension of the EML Sheffer Operator

**Author:** Anthony Monnerot  
**Date:** May 2, 2026  
**Extension of:** Odrzywołek (arXiv:2603.21852v2)

---

## Background

Odrzywołek (2026) showed that a single binary operator  
`eml(x, y) = exp(x) − ln(y)` together with the constant 1  
generates all classical elementary functions (continuous Sheffer basis).

**Structural limitation identified** (Theorem 2.1 / Corollary 2.2):  
eml is holomorphic by construction → z̄, Re(z), Im(z), |z|² are **unreachable**
by any finite eml tree. This result is unconditional.

## Contribution: eml★

```
eml★(x, y) = exp(x) − ln(ȳ)
```

A single conjugate on the second argument is sufficient to reach:

| Result | Depth | Status |
|---|---|---|
| **Cor. 2.2**: Re, Im, conj ∉ {eml, 1} | — | **UNCONDITIONAL** |
| **Th. 3.1**: z̄ = 1 − eml★(0, eml(z,1)) | relative 2 | Conditional: Im(z) ∈ [−π, π) |
| **Th. 3.2**: exact domain [−π, π) | — | Conditional; boundary −π proved via SymPy |
| **Th. 4.3**: A_K is uniformly dense in C(K, ℂ) | — | A_K is the unital complex algebra generated by continuous tree functions on compact K in the open strip. The earlier claim that the arithmetic trees avoid all branch-cut crossings is withdrawn (see correction below). |

## Arithmetic trees: correction (November 2026)

**What was claimed (May 2026) and is withdrawn.** That every composite tree "evaluates without
branch-cut crossings on K" (with the test "1000 random points: zero violations"). This claim is
false for the × tree: it computes ln(ln x), and ln x is a negative real for every real x in (0, 1),
so that logarithm is taken *on* the cut (a 2πi jump, measured). The old test only checked that the
final value was right, which it is. The accompanying assumption, a bound Im ∈ (−π, π] at every
intermediate node, is not refuted by this example, but it is not the relevant condition: it implies
neither the absence of crossings nor continuity. The May script `branch_safety_final.py` is kept
for the record (superseded).

**What is true (short proofs in `eml_star_branch_safety_lemma_proof.tex`, to be refereed).**

- **× tree:** with the principal branch, E_mul(x, y) = x·y for all nonzero x, y; no condition on
  imaginary parts. The value does not change when the branch of a logarithm *whose argument depends
  on x or y* is moved. This is **not** true of the logarithms of constants: taking ln 1 = 2πi in the
  root node alone shifts the result by exactly −2πi (`branches_autorisees.py`).
- **+ tree:** with the principal branch, E_add(x, y) = x + ỹ, where ỹ is y reduced modulo 2πi to
  Im ∈ [−π, π). So E_add(x, y) = x + y exactly when Im y ∈ [−π, π); the condition is on y only.
  (E_add(x, iπ) = x − iπ.)
- **Two-doors rule (sufficient criterion):** a node whose logarithm crosses the cut is harmless when
  it is the *first* argument of its parent (the exponential erases the 2πi jump). In second position
  or at the root that mechanism is not available.
- Evaluation is extended, node by node, to ℂ ∪ {−∞, +∞}: ln 0 = −∞, exp(−∞) = 0, exp(+∞) = +∞
  (needed for the constant sub-trees and at x = 1).

**Computer-assisted certificates (interval arithmetic, two independent implementations).**

| Certificate | Python (`certify_branch_safety.py`, mpmath) | Julia (`julia_check/certify.jl`, IntervalArithmetic.jl) |
|---|---|---|
| × (original tree), x, y ∈ [0.1, 3] + i[−1, 1], minus the disc \|x − 1\| < 0.05 | 75 592 boxes, 22 784 absorbed crossings | identical |
| + on [−3, 3] + i[−3, 3] minus \|Re\|, \|Im\| < 0.1 | 2 056 boxes, 584 absorbed crossings | identical |
| × (with the absorption lemma), same domain | certified | certified |
| + (with the absorption lemma), full square including 0 | certified | certified |

Random-branch check (a random multiple of 2πi added to every logarithm with a variable argument;
logarithms of constants untouched; 4000 points, 80 digits):
× equals x·y to 6·10⁻⁷⁹; + equals x + y up to an integer multiple of 2πi.

Reproduce (each command prints the six certificates of the table and exits with a non-zero status if
one fails): `python3 certify_branch_safety.py` (about 3 minutes), `cd julia_check && julia --project=. certify.jl`.
Decimal bounds are rounded outward and the excluded disc is tested with guaranteed arithmetic.
Branch checks: `python3 mur_et_infini.py`, `python3 branches_autorisees.py`. Full report: `FINDINGS_20261119_branch_safety_certificate.md`.

> **Tree sizes.** The trees used and tested in this repository have RPN length 27 for + (13 eml
> nodes) and 41 for × (20 eml nodes). These lengths coincide with the "EML Compiler" column of
> Odrzywołek's Table 4; the expressions themselves have not been compared symbol by symbol with his
> compiler. The "RPN-length 19 / 17" quoted earlier are the *direct-search* lengths of that table:
> shorter, different expressions, which were **not** the ones tested.

**Also corrected:** `eml_toolkit/core.py` returned wrong values for `E_sub`, `E_add`, `E_mul` and
`modulus_squared` (it computed exp(z) − Log(exp(z)), i.e. exp(z) − z inside the strip), and `eml_toolkit/test_suite.py` silently fell back to
its own definitions instead of testing it. Both are fixed; `eml_toolkit/test_core.py` now imports
`core.py` directly. Outside the strip −π ≤ Im z < π, the conjugation formula of Th. 3.1 returns z̄
reduced modulo 2πi (its real part is always exact).

## Choice by Use Case

- **Uniform symbolic regression (Sheffer)** → **{eml, eml★, 1}**  
  Homogeneous binary grammar `S → 1 | eml(S,S) | eml★(S,S)`.  
  Compatible with Odrzywołek's Rust/Mathematica engine without modification.

- **Physical observables without strip restriction** → **{eml, Re, 1}**  
  z̄ = 2 Re(z) − z, |z|² exact everywhere on ℂ.  
  Note: Re is a unary operator — breaks the uniform binary grammar.

Both bases are valid. The choice depends on the intended application.

## Honest Caveats

- Im(z) ∈ [−π, π) is a condition on the **value** of z, not on its argument.
  For normalized plane waves (|ψ| = 1), it is automatically satisfied.
- Th. 4.3 is a density statement for the algebra A_K (pointwise sums, products,
  complex scalars). Whether single trees are themselves uniformly dense is a
  separate, open question. Exact representation of every element of A_K by one
  finite tree is impossible (countably many trees, uncountably many constants).
  The × and + formulas give sufficient conditions for combining two represented
  functions into one tree (nonzero factors; second summand in Im ∈ [−π, π)).
- The short proofs of the × and + formulas (November 2026) have been checked
  numerically and by interval certificates, but not yet by an external referee.
- The system is limited to elementary functions.

## Implementation: OxiEML-Star

The symbolic-regression engine that puts eml★ to work is maintained
in a companion repository:

**→ https://github.com/antparis/oxieml-star**

While this repository holds the theory (operator definition,
Theorems 3.1 and 4.3, branch-safety analysis), OxiEML-Star provides
the computational pipeline: a PySR-based detector using the toolboxes
{eml, eml★} and {eml, Re}, an exact SymPy judge (`verify_exact.py`)
certifying the holomorphic / anti-holomorphic verdict via the
Wirtinger derivative ∂f/∂z̄, and a synthetic test battery with
judge-certified ground truth.

Software archive: Zenodo DOI 10.5281/zenodo.20152989

## EML-WM — EML World Model (Prototype)

`jepa_real_baseline.py` and `jepa_eml_complex_v2.py` implement a minimal prototype of **EML-WM** (EML World Model) — a complex latent predictive architecture using eml★ and eml⁰ as exact mathematical primitives in the latent predictor.

EML-WM explores whether mathematically exact complex-domain operators improve latent space stability in predictive world models. This is an original architecture — distinct from existing implementations.
