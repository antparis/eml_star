## 1. THE MATHEMATICAL CORE

### 1.1 Starting point: Odrzywołek (2026)

arXiv:2603.21852v2 — "All elementary functions from a single operator"

The operator `eml(x,y) = exp(x) − ln(y)` with constant 1 generates ALL classical
elementary functions. Grammar: `S → 1 | eml(S,S)`. This is the continuous analogue
of the NAND gate in Boolean logic.

### 1.2 The structural limitation we identified

eml is holomorphic by construction. Therefore:

- **Theorem 2.1 (Holomorphic closure):** Every element of E = {eml,1} is holomorphic.
- **Corollary 2.2 (UNCONDITIONAL):** Re, Im, conj ∉ E. Impossible by any finite eml tree.

This means eml alone cannot compute complex conjugate z̄, Re(z), Im(z), or |z|².
This is not a limitation of depth — it is a structural impossibility.

### 1.3 Our contribution: eml★

```
eml★(x, y) = exp(x) − ln(conj(y))
```

A single conjugate on the second argument. Results:

| Result | Depth | Status |
|---|---|---|
| Cor. 2.2: Re, Im, conj ∉ {eml,1} | — | UNCONDITIONAL |
| Th. 3.1: z̄ = 1 − eml★(0, eml(z,1)) | rel. 2 | CONDITIONAL: Im(z) ∈ [−π, π) |
| Th. 3.2: exact domain [−π, π) | — | CONDITIONAL, boundary proved via SymPy |
| Th. 4.3: A_K uniformly dense in C(K, ℂ) | — | Proved via Stone–Weierstrass for the algebra A_K (see 1.4). Density of individual trees: separate, open question |

### 1.4 Theorem 4.3 — Exact wording (corrected November 2026)

**Theorem 4.3.** *Let K ⊂ {z ∈ ℂ : |Im(z)| < π} be compact, and let A_K be the unital
complex subalgebra of C(K, ℂ) generated by the functions computed on K by
{eml, eml★, 1}-trees with leaf z that are defined and continuous on K. Then A_K is
uniformly dense in C(K, ℂ).*

In A_K one may add and multiply functions pointwise and use complex scalars. Whether
individual trees are themselves uniformly dense on K is a **separate, open question**.
For nonempty K, exact representation of every element of A_K by a single finite tree is
impossible (countably many trees, uncountably many complex constants).

**Withdrawn (May 2026 wording).** The earlier statement required the arithmetic trees to
be "branch-safe" and reported that no intermediate node crosses the branch cut. That
conclusion is withdrawn: the multiplication tree computes ln(ln x). For real 0 < x < 1, the
argument ln x of the outer logarithm lies on the negative real axis, i.e. on the cut; an
exponential higher in the tree then erases the 2πi jump, so the final value is still x·y.
The May test (`branch_safety_final.py`, 1000 random points) only checked final values.

**What replaces it** (proofs in `eml_star_branch_safety_lemma_proof.tex`, reviewed by AI
assistants, not yet by a human referee):

- × tree of this repository (20 eml nodes, RPN length 41): with the principal branch and the extended
  evaluation (ln 0 = −∞, exp(−∞) = 0, exp(+∞) = +∞), E_mul(x, y) = x·y for all nonzero x, y.
- + tree of this repository (13 eml nodes, RPN length 27): E_add(x, y) = x + ỹ, ỹ being y reduced modulo 2πi
  to Im ∈ [−π, π); so E_add(x, y) = x + y exactly when Im y ∈ [−π, π).
- Six interval-arithmetic certificates of continuity, each run in Python and in Julia
  (`certify_branch_safety.py`, `julia_check/certify.jl`). Notation: D = [0.1, 3] + i[−1, 1],
  B(1, 0.05) the open disc |x − 1| < 0.05, P = [−3, 3] + i[−3, 3], and Q = P minus the open
  square |Re|, |Im| < 0.1. Pairs are (x, y). The certificates cover these tree forms and
  domains only:
  1. original + tree on D × D;
  2. original × tree on (D \ B(1, 0.05)) × D — the disc is removed for x only;
  3. × tree rewritten with the absorption lemma on D × D;
  4. original + tree on Q × Q;
  5. × tree rewritten with the absorption lemma on Q × Q;
  6. + tree rewritten with the absorption lemma on P × P, 0 included.

## 4. DEPTH CONVENTIONS

The paper uses COMPILER-STYLE depths (Odrzywołek's Section 4.1).
Direct-search gives tighter bounds (his Table 4). This is stated explicitly.

Three different counts must not be mixed: the *depth* of a tree, its number of *eml nodes*,
and Odrzywołek's *RPN length K* = leaves + operators (K = 2 × nodes + 1).

The + and × trees used and tested in this repository have 13 eml nodes (RPN length 27) and
20 eml nodes (RPN length 41). The comparison with his Table 4 bears on *RPN lengths* only:
these two lengths coincide with its "EML Compiler" column (27 and 41). Equal length does not
prove equal expressions: the trees have not been
compared symbol by symbol with `eml_compiler_v4.py`, which is not in this repository, and
the building blocks used here do not all have compiler lengths (x − y: RPN length 11 here,
83 in the compiler column; −x: 17 here, 57 in the compiler column). The direct-search
expressions of Table 4 (RPN length 19 for +, 17 for ×) are shorter and are certainly
**not** the trees tested here.

| Function | Relative depth (eml★ nodes) | Absolute depth (all nodes) | Note |
|---|---|---|---|
| z̄ = conj(z) | 2 | 2 | Theorem 3.1 |
| Re(z) | 3 | ≥30 | via (z + z̄)/2 |
| Im(z) | 3 | ≥30 | via (z − z̄)/2i |
| |z|² | 3 | ≥19 | via z · z̄ |
| |z| | 4 | ≥20 | via sqrt(z · z̄) |
| x + y | — | — | 13 eml nodes, RPN length K = 27 (tree tested here). Table 4: compiler 27, direct search 19 (not tested) |
| x × y | — | — | 20 eml nodes, RPN length K = 41 (tree tested here). Table 4: compiler 41, direct search 17 (not tested) |

## 5. WHAT IS RIGOROUSLY ESTABLISHED

**Unconditional (no caveats):**
- Theorem 2.1 — Every finite eml-composition is holomorphic
- Corollary 2.2 — Re, Im, conj cannot be expressed by eml alone

**Conditional on Im(z) ∈ [−π, π):**
- Theorem 3.1 — z̄ = 1 − eml★(0, eml(z,1)) at depth 2
- Theorem 3.2 — exact domain limitation

**Proved for the algebra A_K, K compact in |Im z| < π (see 1.4):**
- Theorem 4.3 — Stone–Weierstrass density of A_K. Not claimed: density of individual trees.

**Proved by short arguments reviewed by AI assistants, not yet by a human referee:**
- E_mul(x, y) = x·y for all nonzero x, y (tree of this repository, principal branch, extended evaluation)
- E_add(x, y) = x + y exactly when Im y ∈ [−π, π)

**Certified by interval arithmetic (Python and Julia):**
- The six continuity certificates apply to the tree forms and domains listed in Section 1.4.

**Numerically checked (samples, not proofs):**
- Conjugate formula on 10,000 random points in the strip
- Folding property on 10,000 out-of-strip points

**Withdrawn:** "branch-safety of the K=13 (+) and K=20 (×) trees" (13 and 20 eml nodes) in the sense of
"no intermediate branch-cut crossing".

## 6. CAVEAT — NORMALIZED PHYSICAL STATES

The eml★ formulas for |ψ|² apply to wavefunctions bounded in sup-norm by
e^π ≈ 23 (e.g., normalized plane waves on bounded domains, coherent states
with bounded amplitude). General L²(ℝⁿ) states with arbitrary peaks fall
outside the strip and require domain decomposition (left to future work).

## 7. ZENODO ARCHIVE

Odrzywołek's archive: DOI 10.5281/zenodo.19183008 (file `eml_compiler_v4.py`).

The following pseudocode shows the arithmetic trees tested in this repository. They have not
been compared symbol by symbol with that file.

```python
def eml_zero():    return eml(ONE, eml(eml(ONE, ONE), ONE))                    # 3 eml nodes (RPN length 7)
def eml_neg(z):    return eml(eml(ONE,eml(eml(ONE,eml_zero()),ONE)),eml(z,ONE)) # 8 eml nodes (RPN length 17)
def eml_sub(a,b):  return eml(eml_ln(a), eml_exp(b))                           # 5 eml nodes (RPN length 11)
def eml_add(a,b):  return eml_sub(a, eml_neg(b))                               # 13 eml nodes (RPN length 27)
def eml_mul(a,b):  return eml_exp(eml_add(eml_ln(a), eml_ln(b)))               # 20 eml nodes (RPN length 41)
```

These are compiler-style constructions (Odrzywołek's Section 4.1).
